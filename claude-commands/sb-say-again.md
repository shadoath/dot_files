# Say it again, plainly

Restate the previous response. Do not do new work, new research, or add new opinions.

Rules:

- Use Short Simple sentences. One idea per sentence. Do NOT reference the code, commands, or files in the response.
- No metaphors, no analogies. No abstract words when a concrete word exists.
- Do not refer to internal reasoning or previous steps. Only the visible response exists.
- Be succinct. A few sentences or bullets. Give the point first, then the reason.
- If the last response asked a question or proposed an action, state that plainly at the end.
- If there is no previous response, say so and ask what to restate.
